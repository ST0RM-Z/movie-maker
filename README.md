# Movie Maker

A full-stack movie app with a React front-end and a GraphQL back-end (Node.js, Apollo-style schema/resolvers/models).

## Tech Stack

- Front-end: React (Create React App)
- Back-end: Node.js, GraphQL (schema, resolvers, models)

## Getting Started

```bash
cd back-end && npm install && node app.js
cd front-end && npm install && npm start
```
